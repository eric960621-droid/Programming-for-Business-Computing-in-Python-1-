# 基地臺位址選擇 (Base Station Location Selection)

## 📝 題目敘述
一家電信公司計畫在包含 $n$ 個城鎮的區域內設置 $p$ 個無線基地臺。每個城鎮 $i$ 有其座標 $(x_i, y_i)$ 與人口數 $P_i$。

### 核心規則：
1. **覆蓋範圍**：若基地臺與城鎮之間的距離在 $d$ 公里以內，則該城鎮被視為被「覆蓋」。
   * 距離公式：$\sqrt{(x_{i_1} - x_{i_2})^2 + (y_{i_1} - y_{i_2})^2}$
2. **設置地點**：基地臺必須設置在城鎮的位置上。
3. **演算法邏輯（貪婪法）**：
   * 第一步：在所有城鎮中，找出「若蓋在這裡，能覆蓋最多人口」的城鎮。
   * 後續步驟：在剩餘未選中的城鎮中，重複找出「若蓋在這裡，能覆蓋最多**尚未被覆蓋的人口**」的城鎮。
   * 重複上述步驟直到挑選出 $p$ 個城鎮為止。
4. **平手處理**：若有兩個以上的城鎮可覆蓋相同數量的「新」人口，優先選擇**編號較小**的城鎮。

---

## 📥 輸入輸出格式

### 輸入格式
1. 第一列：包含三個整數 $n$、$p$ 和 $d$。
   * $2 \le n \le 1000$
   * $2 \le p \le n$
   * $1 \le d \le 100$
2. 第二列至第 $n+1$ 列：每列包含三個整數 $x_i$、$y_i$ 和 $P_i$，代表第 $i$ 個城鎮的資訊。
   * $-100 \le x_i, y_i \le 100$
   * $1 \le P_i \le 100$
   * 不會有兩個城鎮落在同一個地點。

### 輸出格式
* 輸出一行，依序包含：
  1. 挑選出的 $p$ 個城鎮編號（依照挑選先後順序）。
  2. 最後被覆蓋的總人口數。
* 數字之間請以一個空白間隔。
