# 轉帳金額確認 (Transfer Amount Confirmation)

## 📝 題目敘述
在兩個帳戶之間進行轉帳是常見的金融交易。假設目前有兩個帳戶，其餘額分別為 $x_1$ 與 $x_2$。
我們希望從第一個帳戶轉出 $y$ 元到第二個帳戶，請根據以下規則判斷轉帳後的帳戶餘額：

1.  **餘額充足**：若第一個帳戶餘額足夠扣除 $y$ 元（即 $x_1 \ge y$），則第一個帳戶扣除 $y$ 元，第二個帳戶增加 $y$ 元。
    *   結果：$x_1$ 變為 $x_1 - y$，$x_2$ 變為 $x_2 + y$。
2.  **餘額不足**：若第一個帳戶餘額不夠扣除 $y$ 元（即 $x_1 < y$），則直接將第一個帳戶的所有錢轉出。
    *   結果：$x_1$ 變為 $0$，$x_2$ 變為 $x_2 + x_1$（第二個帳戶增加量為第一個帳戶原本的所有餘額）。

請寫一個程式，讀入 $x_1$、$x_2$ 與 $y$ 之後，判斷兩個帳戶最後各應該變成多少錢。

---

## 📥 輸入輸出格式

### 輸入格式
每筆測試資料包含三行輸入：
*   第一行：一個整數 $x_1$，代表第一個帳戶的初始餘額。
*   第二行：一個整數 $x_2$，代表第二個帳戶的初始餘額。
*   第三行：一個整數 $y$，$代表欲轉帳的金額。
*   範圍限制：$0 \le x_1, x_2, y \le 100,000$。

### 輸出格式
請依照題目規則計算後，在同一行印出兩個整數，中間以一個空白字元隔開：
*   第一個整數：轉帳後第一個帳戶的餘額。
*   第二個整數：轉帳後第二個帳戶的餘額。

---

## 💡 範例說明

| 案例 | 輸入內容 | 輸出結果 | 邏輯說明 |
| :--- | :--- | :--- | :--- |
| **範例 1** | `1000`<br>`2000`<br>`500` | `500 2500` | 餘額充足：$1000 \ge 500$，故扣除 $500$。 |
| **範例 2** | `1000`<br>`2000`<br>`1200` | `0 3000` | 餘額不足：$1000 < 1200$，故 $x_1$ 清空，$x_2$ 增加 $1000$。 |

---

## 🧠 解題思路
本題的核心在於 **條件判斷 (Conditional logic)**：
1.  首先讀取三個變數 $x_1, x_2, y$。
2.  使用 `if-else` 判斷式來檢查 $x_1$ 與 $y$ 的大小關係。
3.  根據判斷結果分別計算新的餘額：
    *   若充足：更新為 $(x_1 - y, x_2 + y)$。
    *   若不足：更新為 $(0, x_2 + x_1)$。
4.  最後依照格式輸出結果。
