# 報童問題之最佳訂貨量 (Optimal Order Quantity for the Newsvendor Problem)

## 📝 題目敘述
本題為「報童問題：計算預期利潤」的延伸應用。在已知進貨成本 $c$、零售價格 $r$ 以及需求量機率分佈 $p_i$ 的情況下，目標不再是計算單一訂貨量的利潤，而是要找出能**最大化預期利潤**的最佳訂貨量 $q^*$。

### 核心任務：
1.  **尋找最佳訂貨量 ($q^*$)**：在所有可能的訂貨量（從 $0$ 到 $N$）中，找出一個 $q$ 使得預期利潤 $\pi(q)$ 最大。
2.  **利潤計算**：預期利潤公式維持不變：
    $$\pi(q) = r\mathbb{E}[\min\{q, D\}] - cq$$
3.  **平手規則**：如果有數個訂貨量 $q$ 導致一模一樣的預期利潤，請選擇**較小**的那一個作為最佳訂貨量 $q^*$。

---

## 📥 輸入輸出格式

### 輸入格式
每筆測試資料總共有 $N + 4$ 列：
1. 第一列：單位進貨成本 $c$。
2. 第二列：單位零售價格 $r$。
3. 第三列：需求的可能個數 $N$。
4. 第四列開始：依序為需求量為 $0, 1, \dots, N$ 的機率 $p_i$。

*   $1 \le c, r \le 100$ 且 $r \ge c$。
*   $N$ 固定為 $8$。
*   機率 $p_i$ 介於 $0$ 到 $1$ 之間，且總和為 $1$。

### 輸出格式
輸出兩個數值，中間用一個空格隔開：
1. **最佳訂貨量 $q^*$**。
2. 該訂貨量下的**預期利潤無條件捨去至整數** $\lfloor \pi(q^*) \rfloor$。

---

## 💡 範例說明

若輸入資料如下：
*   $c = 2, r = 10, N = 8$
*   機率分佈與前一題相同。

**運算過程：**
*   程式需分別計算 $q = 0, 1, 2, \dots, 8$ 時的預期利潤。
*   經計算後，當 $q=4$ 時，預期利潤最大（約為 $18.5$）。
*   **輸出結果**：`4 18`

## 📊 複雜度分析

| 維度 | 複雜度 | 說明 |
| :--- | :--- | :--- |
| **時間複雜度** | $O(N^2)$ | 需遍歷 $N+1$ 種訂貨量，每種需 $O(N)$ 計算期望值。 |
| **空間複雜度** | $O(N)$ | 用於儲存機率分佈。 |
