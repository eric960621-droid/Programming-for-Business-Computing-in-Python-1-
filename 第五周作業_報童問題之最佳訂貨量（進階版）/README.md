# 報童問題之最佳訂貨量：進階版 (Optimal Order Quantity: Advanced)

## 📝 題目敘述
本題為「報童問題」的延伸。與基礎版最大的不同在於：
1. **殘值 (Salvage Value)**：每一份沒賣出去的報紙，在一天結束時可以以每份 $s$ 元的殘值當作廢紙賣掉。
2. **變動的需求上限**：需求的可能個數 $N$ 不再侷限於 8，需視輸入而定。

### 核心變數：
*   $c$：每份報紙的**進貨成本**。
*   $r$：每份報紙的**零售價格**。
*   $s$：每份報紙的**殘值**。
*   $D$：隨機的**單日需求量**。
*   $q$：你的**訂貨量**。
*   $p_i$：需求量剛好為 $i$ 的機率，即 $\Pr(D = i) = p_i$。

### 期望利潤公式：
進階版的期望利潤 $\pi(q)$ 加入了預期總殘值的收益：
$$\pi(q) = r\mathbb{E}[\min\{q, D\}] - cq + s\mathbb{E}[\max\{q - D, 0\}]$$

其中：
*   $r\mathbb{E}[\min\{q, D\}]$ 為預期銷售收益。
*   $cq$ 為進貨成本。
*   $s\mathbb{E}[\max\{q - D, 0\}]$ 為預期總殘值（即沒賣掉份數的預期收益）。

---

## 📥 輸入輸出格式

### 輸入格式
每筆測試資料總共有 $N + 5$ 列：
1. 第一列：單位進貨成本 $c$。
2. 第二列：單位零售價格 $r$。
3. 第三列：需求的可能上限 $N$。
4. 第四列：單位殘值 $s$。
5. 第五列開始：依序為需求量為 $0, 1, \dots, N$ 的機率 $p_i$。

*   $1 \le c, r, s, N \le 1000$
*   $r \ge c \ge s$
*   機率 $p_i$ 總和為 $1$。

### 輸出格式
輸出兩個數值，中間用一個空格隔開：
1. **最佳訂貨量 $q^*$**：使期望利潤最大化的訂貨量（若有利潤相同者，取 $q$ 較小者）。
2. **最大預期利潤**：無條件捨去至整數 $\lfloor \pi(q^*) \rfloor$。

---

## 💡 範例說明

若輸入資料如下：
*   $c = 2, r = 10, N = 10, s = 1$
*   機率分佈如題目附件所示。

**運算邏輯：**
*   計算 $q$ 從 $0$ 到 $N$ 每一種可能的期望利潤。
*   考慮殘值後，最理想的訂貨量為 $5$。
*   當 $q=5$ 時，預期利潤 $\pi(5) \approx 20.47$。
*   **輸出結果**：`5 20`

---

## 🧠 解題思路
1.  **動態處理 N**：由於 $N$ 是變動的，請使用動態列表或陣列來儲存機率。
2.  **雙重迴圈計算**：
    *   外層迴圈：測試每一種訂貨量 $q \in [0, N]$。
    *   內層迴圈：針對特定 $q$，遍歷所有需求 $i \in [0, N]$。
    *   計算利潤：
        *   若 $i \le q$（需求小於等於訂購）：利潤為 $r \times i - c \times q + s \times (q - i)$。
        *   若 $i > q$（需求大於訂購）：利潤為 $r \times q - c \times q$（無殘值）。
3.  **最優解追蹤**：記錄最大利潤及其對應的 $q$，同樣注意平手時取較小 $q$ 的原則。

## 📊 複雜度分析

| 維度 | 複雜度 | 說明 |
| :--- | :--- | :--- |
| **時間複雜度** | $O(N^2)$ | 需測試 $N+1$ 種訂貨量，每種需 $N+1$ 次加權計算。 |
| **空間複雜度** | $O(N)$ | 用於儲存機率分佈。 |
