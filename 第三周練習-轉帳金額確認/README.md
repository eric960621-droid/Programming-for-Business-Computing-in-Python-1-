# 轉帳金額確認 (Transfer Amount Confirmation)

## 📝 題目敘述
在兩個帳戶之間轉帳是非常普遍的金融交易。假設我們現在有兩個帳戶，戶頭金額各為 $x_1$ 和 $x_2$。

當我們想從第一個帳戶轉出 $y$ 元到第二個帳戶時，規則如下：
1. **正常情況**：若第一個帳戶餘額充足（ $x_1 \ge y$），則兩個戶頭的金額分別變為 $x_1 - y$ 和 $x_2 + y$。
2. **餘額不足**：若第一個帳戶錢不夠（ $x_1 < y$），則將第一個帳戶的錢全部扣除變為 $0$，並將這筆錢全部轉入第二個帳戶，使其變為 $x_2 + x_1$。

請撰寫一個程式，讀入 $x_1$、 $x_2$ 和 $y$ 之後，判斷兩個帳戶最後各應該變成多少錢。

---

## 📥 輸入輸出格式

### 輸入格式
每筆測試資料包含三行輸入：
1. 第一行：一個整數 $x_1$，代表第一個帳戶的初始金額。
2. 第二行：一個整數 $x_2$，代表第二個帳戶的初始金額。
3. 第三行：一個整數 $y$，代表欲轉帳的金額。
*   已知 $x_1$、 $x_2$ 和 $y$ 都介於 $0$ 到 $100,000$ 之間。

### 輸出格式
依序印出轉帳後的第一個帳戶餘額與第二個帳戶餘額。
*   兩個整數之間用一個空白字元隔開。

---

## 💡 範例說明

| 輸入 ($x_1, x_2, y$) | 輸出結果 | 說明 |
| :--- | :--- | :--- |
| `1000`, `2000`, `500` | `500 2500` | 餘額充足，扣除 500 並加到對方帳戶。 |
| `1000`, `2000`, `1200` | `0 3000` | 餘額不足，帳戶 1 歸零，1000 元全數轉入帳戶 2。 |

---

## 🧠 解題思路
本題的核心在於 **條件判斷 (If-Else Logic)** 或使用 **取最大/最小值 (Max/Min)** 的概念：
1. 讀取三個整數 $x_1, x_2, y$。
2. 判斷轉帳金額 $y$ 是否大於現有餘額 $x_1$：
    - 若 $y > x_1$：實際轉帳金額為 $x_1$。
    - 若 $y \le x_1$：實際轉帳金額為 $y$。
3. 計算最終金額：
    - 帳戶 1：`max(0, x1 - y)`
    - 帳戶 2：`x2 + (實際轉帳金額)`
