# 報童問題之預期利潤 (Expected Profit of the Newsvendor Problem)

## 📝 題目敘述
報童問題（Newsvendor Problem）是作業管理（Operations Management）領域的經典存貨管理問題。你經營一家報攤，必須在今天下午決定明天的訂貨量 $q$。

### 核心變數：
*   $c$：每份報紙的**進貨成本**。
*   $r$：每份報紙的**零售價格**。
*   $D$：隨機的**單日需求量**。
*   $q$：你的**訂貨量**。
*   $p_i$：需求量剛好為 $i$ 的機率，即 $\Pr(D = i) = p_i$。

### 期望利潤公式：
期望利潤 $\pi(q)$ 的計算方式為「預期銷售收益」減去「進貨成本」：
$$\pi(q) = r\mathbb{E}[\min\{q, D\}] - cq$$

其中：
*   $\min\{q, D\}$ 為明天的實際銷售量（訂貨量與需求量中的較小值）。
*   $\mathbb{E}[\min\{q, D\}]$ 為預期銷售量。
*   $cq$ 為必須支付給報社的固定成本。

---

## 📥 輸入輸出格式

### 輸入格式
每筆測試資料總共有 $N + 5$ 列（本題 $N$ 固定為 $8$）：
1. 第一列：單位進貨成本 $c$。
2. 第二列：單位零售價格 $r$。
3. 第三列：需求的可能個數 $N$。
4. 第四列：訂貨量 $q$。
5. 第五列開始：依序為賣出 $0, 1, \dots, N$ 份報紙的機率 $p_i$。

*   $1 \le c \le 100$
*   $1 \le r \le 100$ ($r \ge c$)
*   $N = 8$
*   $0 \le p_i \le 1$ 且 $\sum_{i=0}^{N} p_i = 1$

### 輸出格式
輸出在給定訂貨量 $q$ 下的預期利潤，並**無條件捨去至整數** $\lfloor \pi(q) \rfloor$。

---

## 💡 範例說明

若輸入資料如下：
*   $c = 2, r = 10, N = 8, q = 6$
*   機率分佈：$p_0=0.06, p_1=0.15, p_2=0.22, p_3=0.22, p_4=0.17, p_5=0.1, p_6=0.05, p_7=0.02, p_8=0.01$

**期望利潤計算：**
1. 當 $D < q$ 時，收益為 $r \times D - c \times q$。
2. 當 $D \ge q$ 時，收益為 $r \times q - c \times q$。
3. 經計算後 $\pi(6) \approx 17.1$。
4. **輸出結果**：`17`
